# zig-userdemo (M5PaperS3 UserDemo port)

This is a Zig/WASM port of the upstream M5PaperS3 UserDemo dashboard app.

## Build and Deploy

From the repo root: `zig build deploy`

## Naming conventions (Zig)

Use `lowerCamelCase` for all functions, except functions that return a type (Zig), which use `PascalCase`.
